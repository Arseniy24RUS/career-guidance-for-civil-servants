# Roadmap

This roadmap keeps research-readiness work visible without promising a fixed release schedule.

## Near term

- Keep methodology, licensing, and third-party notices current.
- Add a small documented audit command or script for questionnaire counts, reverse-coded items, and agency profile dimensions.
- Improve README and documentation link checks so contributors can run them locally.
- Review accessibility basics: keyboard navigation, focus visibility, color contrast, and chart alternatives.
- Keep EN/RU interface tests stable across desktop and mobile viewports.

## Research-readiness

- Move questionnaire items and agency profiles from inline JavaScript into a documented data file.
- Add source notes or coding rationale for agency profile values.
- Define a versioning convention for questionnaire and profile changes.
- Prepare a pilot-study template for instructors who want to collect classroom feedback.
- Document optional reliability checks for future anonymized research datasets.

## Teaching materials

- Add a short facilitator guide for classroom discussion.
- Add example interpretation notes for high, balanced, and mixed profiles.
- Add an adaptation worksheet for other courses or agency sets.

# Дорожная карта

Эта дорожная карта фиксирует задачи исследовательской готовности, но не обещает жесткий график релизов.

## Ближайшие задачи

- Поддерживать актуальность методологии, лицензий и уведомлений о сторонних материалах.
- Добавить небольшую документированную команду или скрипт аудита числа вопросов, обратных пунктов и размерностей профилей органов.
- Улучшить локальную проверку ссылок и изображений README.
- Проверить базовую доступность: клавиатурную навигацию, видимость фокуса, контраст и альтернативы диаграмме.
- Сохранять стабильность EN/RU тестов интерфейса для desktop и mobile.

## Исследовательская готовность

- Вынести пункты анкеты и профили органов из inline JavaScript в документированный файл данных.
- Добавить источники или правила кодирования для значений профилей органов.
- Задать правило версионирования изменений анкеты и профилей.
- Подготовить шаблон пилотажного исследования для преподавателей, собирающих обратную связь.
- Описать необязательные проверки надежности для будущих обезличенных исследовательских данных.

## Учебные материалы

- Добавить краткое руководство для модератора аудиторного обсуждения.
- Добавить примеры интерпретации для высоких, сбалансированных и смешанных профилей.
- Добавить лист адаптации для других курсов или наборов органов.
