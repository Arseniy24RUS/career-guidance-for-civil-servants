# Good First Issues

Small, well-scoped contributions are especially useful in this repository. A good first issue should improve clarity or reproducibility without changing the core scoring model unexpectedly.

## Good candidates

- Add a reusable README local image/link check.
- Extract the questionnaire and agency profiles into a documented JSON data file.
- Add source notes for a small group of agency profile values.
- Improve keyboard focus visibility and document the accessibility check.
- Add short alt-text or text fallback guidance for the radar chart.
- Expand the methodology FAQ with one clear question and answer.
- Add a classroom discussion worksheet linked from the README.
- Review EN/RU wording for one documentation page and suggest precise edits.

## Before starting

- Read [CONTRIBUTING.md](../CONTRIBUTING.md).
- Read [docs/methodology.md](methodology.md) if your change touches questionnaire logic, scales, profiles, or interpretation.
- Keep pull requests small.
- Run `npm run test:i18n` before asking for review.

# Хорошие первые задачи

Небольшие четко ограниченные изменения особенно полезны для этого репозитория. Хорошая первая задача улучшает понятность или воспроизводимость и не меняет неожиданно основную модель расчета.

## Подходящие задачи

- Добавить переиспользуемую проверку локальных изображений и ссылок README.
- Вынести анкету и профили органов в документированный JSON-файл.
- Добавить источники или пояснения для небольшой группы значений профилей органов.
- Улучшить видимость клавиатурного фокуса и описать проверку доступности.
- Добавить краткие рекомендации по alt-тексту или текстовой альтернативе радарной диаграмме.
- Расширить методологический FAQ одним ясным вопросом и ответом.
- Добавить лист для аудиторного обсуждения и ссылку из README.
- Проверить EN/RU формулировки одной страницы документации и предложить точечные правки.

## Перед началом

- Прочитайте [CONTRIBUTING.md](../CONTRIBUTING.md).
- Прочитайте [docs/methodology.md](methodology.md), если изменение затрагивает логику анкеты, шкалы, профили или интерпретацию.
- Делайте pull request небольшим.
- Запустите `npm run test:i18n` перед запросом ревью.
